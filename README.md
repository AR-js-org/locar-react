# locar-react

A lightweight [react-three-fiber](https://r3f.docs.pmnd.rs)-based React wrapper for [LocAR.js](https://github.com/AR-js-org/locar.js).
The main aim is to bring React Native support to LocAR.js in the (hopefully) near future.

See the `examples` directory for examples.

Currently not published to npm. Please `npm run build` to generate a tarball and use that as your dependency.

If you wish to work with LocAR and React solely on the web platform, [RDK](https://github.com/omnidotdev/rdk) is recommended.
